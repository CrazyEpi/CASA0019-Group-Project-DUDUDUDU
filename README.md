# CASA0019 Group Project — DUDUDUDU

## 1. Project Overview
**DUDUDUDU** is a CASA0019 course group project that brings together physical prototyping, sensing/interaction, and digital presentation. This repository serves as the **final submission package** and includes the project demonstration materials (videos/images), an Android application package, a web-based showcase page, and supporting files for prototyping and data visualization.

**Repository focus:** deliverables + showcase (rather than a single build-from-source codebase).

---

## 2. Objectives
The project was developed to:

- Produce a working prototype and demonstrate its usage in real-world contexts
- Provide a clear, review-friendly project presentation (web page + media)
- Package the mobile-side experience as an installable Android app (APK)
- Document and organize assets produced during development (e.g., 3D printing and visualization work)

---

## 3. Deliverables (Submission Checklist)

### 3.1 Web Showcase
- **Entry file:** `index.html`  
A simple web page used to present the project content (recommended as the landing page for GitHub Pages).

### 3.2 Android Application
- **APK:** `NoiseGuard.apk`  
Installable Android package for the mobile component of the project.

### 3.3 Demonstration Media
- **Device demo video:** `device_video.mp4`
- **AR demo video:** `ARvideo.mp4`
- **Device photo:** `device_photo.jpg`

### 3.4 Supporting Work Folders
- `0019_3dPrinting/` — 3D printing related files (models/exports/notes as applicable)
- `groupwork_data_visual/` — Program-related files
- `scan mark/` — scanning markers / recognition assets for digital twin

---

## 4. How to Run / View

### 4.1 View the Web Showcase
1. Enable GitHub Pages for this repository
2. Use the deployed URL as the project landing page for assessment/demo

### 4.2 Install the Android App (APK)
1. Download `NoiseGuard.apk` onto an Android phone
2. Install the APK  
   - Android may block installs by default; allow “Install unknown apps” in settings if prompted

### 4.3 Watch the Demos
- Open the included `.mp4` files directly in the browser or a media player.
